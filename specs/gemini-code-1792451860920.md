## 1. Goal & Core Architectural Constraint (CRITICAL)

## 2. Research Summary & Domain Mechanics

### How Salesforce Flow Mutation Testing Works
1. **Target Artifact:** A local Salesforce Flow XML file (`*.flow-meta.xml`) using namespace `http://soap.sforce.com/2006/04/metadata`.
2. **Test Suite (Oracle):** Standard Apex Test Classes (`--test-class`) that trigger the Flow (directly or via DML operations like `insert account`) and assert the side effects.
3. **Coverage-Guided Filtering via Tooling API:**
   Salesforce tracks Flow coverage per test method in the Tooling API:
   - `FlowTestCoverage`: Links `ApexTestClassId`, `TestMethodName`, and `FlowVersionId`.
   - `FlowElementTestCoverage`: Stores `ElementName` (matching `<name>` inside `.flow-meta.xml`) covered by a test run.
   - *Fallback:* If per-element coverage is unavailable or returns empty (e.g., for `<formulas>` or `<start>` tags which are not always logged as separate executable elements in `FlowElementTestCoverage`), run all specified test classes against the mutant.
4. **Mutation Lifecycle:**
   - Parse the target `.flow-meta.xml` into an XML DOM.
   - Run all registered `FlowMutator` implementations to produce `FlowMutant[]` (each containing a mutated XML string, mutator name, target element name, and human-readable description).
   - Filter mutants by covered elements (always include global nodes like `<start>` and `<formulas>`).
   - In a `try / finally` block (to guarantee original `.flow-meta.xml` restoration on disk and on the Org):
     - For each mutant: deploy the mutated `.flow-meta.xml` to the Org, execute the covering Apex tests, and classify as:
       - `Killed` (at least one Apex test failed),
       - `Survived` (all Apex tests passed),
       - `CompileError` (Salesforce rejected the mutated Flow XML deployment).
   - Restore original `.flow-meta.xml` and print the mutation score summary table.

## 3. Dependencies to Add

Install the following XML DOM manipulation packages:
```bash
npm install @xmldom/xmldom xpath
npm install -D @types/xpath
```

### Why `@xmldom/xmldom` + `xpath`?
- Salesforce Metadata API validates XML element ordering strictly against its internal XSD.
- Object-based parsers (`xml2js`, `fast-xml-parser`) can reorder keys when serializing back to XML, causing false-positive `CompileError` deployments.
- `@xmldom/xmldom` mutates text nodes in-place within the W3C DOM tree, preserving 100% of sibling ordering, attributes, and formatting.
- **Namespace Note:** Salesforce Flow files declare a default namespace `xmlns="http://soap.sforce.com/2006/04/metadata"`. Always configure XPath with:
  ```ts
  const select = xpath.useNamespaces({ sf: '[http://soap.sforce.com/2006/04/metadata](http://soap.sforce.com/2006/04/metadata)' });
  ```

### 5.2. `src/flow/xml/FlowXmlDom.ts`

```typescript
import { DOMParser, XMLSerializer } from '@xmldom/xmldom';
import * as xpath from 'xpath';

export const SF_NAMESPACE = '[http://soap.sforce.com/2006/04/metadata](http://soap.sforce.com/2006/04/metadata)';

export class FlowXmlDom {
  private readonly doc: Document;
  private readonly select: xpath.XPathSelect;

  private constructor(xmlContent: string) {
    this.doc = new DOMParser().parseFromString(xmlContent, 'text/xml');
    this.select = xpath.useNamespaces({ sf: SF_NAMESPACE });
  }

  public static parse(xmlContent: string): FlowXmlDom {
    return new FlowXmlDom(xmlContent);
  }

  public queryNodes(xpathExpr: string, contextNode?: Node): Node[] {
    return this.select(xpathExpr, contextNode ?? this.doc) as Node[];
  }

  public getText(xpathExpr: string, contextNode?: Node): string | undefined {
    const nodes = this.queryNodes(xpathExpr, contextNode);
    if (nodes.length === 0 || !nodes[0].firstChild) {
      return undefined;
    }
    return nodes[0].textContent ?? undefined;
  }

  public serialize(): string {
    return new XMLSerializer().serializeToString(this.doc);
  }
}
```

### 5.3. Mutators (`src/flow/mutators/`)

#### `src/flow/mutators/RecordTriggerTypeMutator.ts`
```typescript
import { FlowMutant, FlowMutator } from '../types.js';
import { FlowXmlDom } from '../xml/FlowXmlDom.js';

const TRIGGER_REPLACEMENTS: Record<string, string[]> = {
  Create: ['Update'],
  Update: ['Create'],
  CreateAndUpdate: ['Create', 'Update'],
};

export class RecordTriggerTypeMutator implements FlowMutator {
  public readonly name = 'RecordTriggerTypeMutator';

  public mutate(xmlContent: string): Omit<FlowMutant, 'id' 'status' |>[] {
    const results: Omit<FlowMutant, 'id' 'status' |>[] = [];
    const dom = FlowXmlDom.parse(xmlContent);
    const triggerNodes = dom.queryNodes('//sf:start/sf:recordTriggerType');

    if (triggerNodes.length === 0) {
      return results;
    }

    const originalValue = triggerNodes[0].textContent?.trim() ?? '';
    const replacements = TRIGGER_REPLACEMENTS[originalValue] ?? [];

    for (const replacement of replacements) {
      const clonedDom = FlowXmlDom.parse(xmlContent);
      const targetNode = clonedDom.queryNodes('//sf:start/sf:recordTriggerType')[0];
      targetNode.textContent = replacement;

      results.push({
        mutatorName: this.name,
        elementName: '$Start',
        description: `Changed recordTriggerType from '${originalValue}' to '${replacement}'`,
        originalSnippet: `<recordTriggerType>${originalValue}</recordTriggerType>`,
        mutatedSnippet: `<recordTriggerType>${replacement}</recordTriggerType>`,
        mutatedXml: clonedDom.serialize(),
      });
    }

    return results;
  }
}
```

#### `src/flow/mutators/FormulaExpressionMutator.ts`
```typescript
import { FlowMutant, FlowMutator } from '../types.js';
import { FlowXmlDom } from '../xml/FlowXmlDom.js';

export class FormulaExpressionMutator implements FlowMutator {
  public readonly name = 'FormulaExpressionMutator';

  public mutate(xmlContent: string): Omit<FlowMutant, 'id' 'status' |>[] {
    const results: Omit<FlowMutant, 'id' 'status' |>[] = [];
    const baseDom = FlowXmlDom.parse(xmlContent);
    const formulaNodes = baseDom.queryNodes('//sf:formulas');

    formulaNodes.forEach((formulaNode, formulaIndex) => {
      const formulaName = baseDom.getText('sf:name', formulaNode) ?? `Formula_${formulaIndex}`;
      const exprText = baseDom.getText('sf:expression', formulaNode);

      if (!exprText) return;

      // 1. Mutate non-empty string literals in single quotes: 'High' -> 'MUTATED_LITERAL'
      const literalRegex = /'([^']+)'/g;
      let match: RegExpExecArray | null;

      while ((match = literalRegex.exec(exprText)) !== null) {
        const fullMatch = match[0];
        const matchIndex = match.index;
        const mutatedExpr =
          exprText.slice(0, matchIndex) + "''" + exprText.slice(matchIndex + fullMatch.length);

        const clonedDom = FlowXmlDom.parse(xmlContent);
        const targetFormula = clonedDom.queryNodes('//sf:formulas')[formulaIndex];
        const targetExprNode = clonedDom.queryNodes('sf:expression', targetFormula)[0];
        targetExprNode.textContent = mutatedExpr;

        results.push({
          mutatorName: this.name,
          elementName: formulaName,
          description: `Replaced string literal ${fullMatch} with '' in formula '${formulaName}'`,
          originalSnippet: fullMatch,
          mutatedSnippet: "''",
          mutatedXml: clonedDom.serialize(),
        });
      }

      // 2. Mutate binary comparison/logical operators (&& <-> ||, == <-> !=)
      const operatorPairs: Array<[string, string]> = [
        ['&&', '||'],
        ['||', '&&'],
        ['==', '!='],
        ['!=', '=='],
      ];

      for (const [opFrom, opTo] of operatorPairs) {
        if (exprText.includes(opFrom)) {
          const mutatedExpr = exprText.replace(opFrom, opTo);
          const clonedDom = FlowXmlDom.parse(xmlContent);
          const targetFormula = clonedDom.queryNodes('//sf:formulas')[formulaIndex];
          const targetExprNode = clonedDom.queryNodes('sf:expression', targetFormula)[0];
          targetExprNode.textContent = mutatedExpr;

          results.push({
            mutatorName: this.name,
            elementName: formulaName,
            description: `Replaced operator '${opFrom}' with '${opTo}' in formula '${formulaName}'`,
            originalSnippet: opFrom,
            mutatedSnippet: opTo,
            mutatedXml: clonedDom.serialize(),
          });
        }
      }
    });

    return results;
  }
}
```

#### `src/flow/mutators/ConnectorBypassMutator.ts`
```typescript
import { FlowMutant, FlowMutator } from '../types.js';
import { FlowXmlDom } from '../xml/FlowXmlDom.js';

const BYPASSABLE_TAGS = ['subflows', 'recordCreates', 'recordUpdates', 'recordDeletes', 'assignments', 'actionCalls'];

export class ConnectorBypassMutator implements FlowMutator {
  public readonly name = 'ConnectorBypassMutator';

  public mutate(xmlContent: string): Omit<FlowMutant, 'id' 'status' |>[] {
    const results: Omit<FlowMutant, 'id' 'status' |>[] = [];
    const baseDom = FlowXmlDom.parse(xmlContent);

    for (const tag of BYPASSABLE_TAGS) {
      const nodes = baseDom.queryNodes(`//sf:${tag}`);

      nodes.forEach((node) => {
        const elementName = baseDom.getText('sf:name', node);
        const outgoingTarget = baseDom.getText('sf:connector/sf:targetReference', node);

        // We can bypass a node if it has a known name and a downstream connector targetReference
        if (!elementName || !outgoingTarget) return;

        // Find all incoming targetReferences pointing to this elementName
        const incomingRefs = baseDom.queryNodes(
          `//sf:targetReference[text()='${elementName}']`
        );

        if (incomingRefs.length === 0) return;

        const clonedDom = FlowXmlDom.parse(xmlContent);
        const clonedIncomingRefs = clonedDom.queryNodes(
          `//sf:targetReference[text()='${elementName}']`
        );

        for (const refNode of clonedIncomingRefs) {
          refNode.textContent = outgoingTarget;
        }

        results.push({
          mutatorName: this.name,
          elementName,
          description: `Bypassed ${tag} element '${elementName}' by rewiring incoming connectors directly to '${outgoingTarget}'`,
          originalSnippet: `<targetReference>${elementName}</targetReference>`,
          mutatedSnippet: `<targetReference>${outgoingTarget}</targetReference>`,
          mutatedXml: clonedDom.serialize(),
        });
      });
    }

    return results;
  }
}
```

#### `src/flow/mutators/DecisionOperatorMutator.ts`
```typescript
import { FlowMutant, FlowMutator } from '../types.js';
import { FlowXmlDom } from '../xml/FlowXmlDom.js';

const OPERATOR_INVERSIONS: Record<string, string> = {
  EqualTo: 'NotEqualTo',
  NotEqualTo: 'EqualTo',
  GreaterThan: 'LessThanOrEqualTo',
  LessThanOrEqualTo: 'GreaterThan',
  LessThan: 'GreaterThanOrEqualTo',
  GreaterThanOrEqualTo: 'LessThan',
  IsNull: 'IsVisited',
};

export class DecisionOperatorMutator implements FlowMutator {
  public readonly name = 'DecisionOperatorMutator';

  public mutate(xmlContent: string): Omit<FlowMutant, 'id' 'status' |>[] {
    const results: Omit<FlowMutant, 'id' 'status' |>[] = [];
    const baseDom = FlowXmlDom.parse(xmlContent);
    const decisionNodes = baseDom.queryNodes('//sf:decisions');

    decisionNodes.forEach((decisionNode, dIdx) => {
      const decisionName = baseDom.getText('sf:name', decisionNode) ?? `Decision_${dIdx}`;
      const operatorNodes = baseDom.queryNodes('.//sf:conditions/sf:operator', decisionNode);

      operatorNodes.forEach((opNode, opIdx) => {
        const currentOp = opNode.textContent?.trim() ?? '';
        const invertedOp = OPERATOR_INVERSIONS[currentOp];
        if (!invertedOp) return;

        const clonedDom = FlowXmlDom.parse(xmlContent);
        const targetDecision = clonedDom.queryNodes('//sf:decisions')[dIdx];
        const targetOpNode = clonedDom.queryNodes('.//sf:conditions/sf:operator', targetDecision)[opIdx];
        targetOpNode.textContent = invertedOp;

        results.push({
          mutatorName: this.name,
          elementName: decisionName,
          description: `Inverted condition operator '${currentOp}' to '${invertedOp}' in decision '${decisionName}'`,
          originalSnippet: `<operator>${currentOp}</operator>`,
          mutatedSnippet: `<operator>${invertedOp}</operator>`,
          mutatedXml: clonedDom.serialize(),
        });
      });
    });

    return results;
  }
}
```

### 5.4. `src/flow/FlowMutationOrchestrator.ts`

```typescript
import * as fs from 'node:fs/promises';
import { FlowMutant, FlowMutator, FlowMutationReport, FlowSalesforcePort } from './types.js';
import { RecordTriggerTypeMutator } from './mutators/RecordTriggerTypeMutator.js';
import { FormulaExpressionMutator } from './mutators/FormulaExpressionMutator.js';
import { ConnectorBypassMutator } from './mutators/ConnectorBypassMutator.js';
import { DecisionOperatorMutator } from './mutators/DecisionOperatorMutator.js';

export interface OrchestratorOptions {
  flowFilePath: string;
  flowDeveloperName: string;
  testClasses: string[];
  dryRun?: boolean;
}

export class FlowMutationOrchestrator {
  private readonly mutators: FlowMutator[];

  public constructor(
    private readonly sfPort: FlowSalesforcePort,
    customMutators?: FlowMutator[]
  ) {
    this.mutators = customMutators ?? [
      new RecordTriggerTypeMutator(),
      new FormulaExpressionMutator(),
      new ConnectorBypassMutator(),
      new DecisionOperatorMutator(),
    ];
  }

  public async run(options: OrchestratorOptions): Promise<FlowMutationReport> {
    const originalXml = await fs.readFile(options.flowFilePath, 'utf-8');

    // 1. Generate all candidate mutants
    const rawMutants = this.mutators.flatMap((m) => m.mutate(originalXml));
    const mutants: FlowMutant[] = rawMutants.map((m, idx) => ({
      ...m,
      id: `FLOW-MUT-${idx + 1}`,
      status: 'Pending',
    }));

    if (options.dryRun || mutants.length === 0) {
      return this.buildReport(options.flowFilePath, mutants);
    }

    // 2. Baseline check: verify original Flow deploys and baseline tests pass
    const baselineDeploy = await this.sfPort.deployFlowXml(options.flowFilePath, originalXml);
    if (!baselineDeploy.success) {
      throw new Error(`Baseline Flow deployment failed: ${baselineDeploy.errorMessage}`);
    }

    const baselineTests = await this.sfPort.runApexTests(options.testClasses);
    if (!baselineTests.allPassed) {
      throw new Error(
        `Baseline Apex tests failed before mutation started: ${baselineTests.failingMethods.join(', ')}`
      );
    }

    // 3. Execute mutation loop with guaranteed restoration in finally
    try {
      for (const mutant of mutants) {
        const deployResult = await this.sfPort.deployFlowXml(options.flowFilePath, mutant.mutatedXml);

        if (!deployResult.success) {
          mutant.status = 'CompileError';
          continue;
        }

        const testResult = await this.sfPort.runApexTests(options.testClasses);
        if (!testResult.allPassed) {
          mutant.status = 'Killed';
          mutant.killedBy = testResult.failingMethods;
        } else {
          mutant.status = 'Survived';
        }
      }
    } finally {
      // ALWAYS restore original Flow XML on disk and on the Org
      await fs.writeFile(options.flowFilePath, originalXml, 'utf-8');
      await this.sfPort.deployFlowXml(options.flowFilePath, originalXml);
    }

    return this.buildReport(options.flowFilePath, mutants);
  }

  private buildReport(flowFilePath: string, mutants: FlowMutant[]): FlowMutationReport {
    const killed = mutants.filter((m) => m.status === 'Killed').length;
    const survived = mutants.filter((m) => m.status === 'Survived').length;
    const compileErrors = mutants.filter((m) => m.status === 'CompileError').length;
    const validTotal = killed + survived;
    const mutationScore = validTotal > 0 ? Math.round((killed / validTotal) * 10000) / 100 : 0;

    return {
      flowFilePath,
      totalMutants: mutants.length,
      killed,
      survived,
      compileErrors,
      mutationScore,
      mutants,
    };
  }
}
```
